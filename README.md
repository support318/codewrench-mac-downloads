# CodeWrench for macOS

Public distribution repository for signed and notarized CodeWrench Apple Silicon releases.

The automatic update feed is `https://github.com/support318/codewrench-mac-downloads/releases/latest/download/latest-mac.yml` once the first verified release is published. Artifacts use immutable versioned release URLs.

This repository is separate from the Windows update channel. Release publication requires Apple code-signature, notarization and Gatekeeper verification. No release is available until those checks pass.
